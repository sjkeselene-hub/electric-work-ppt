核心结论电流做功 W = UIt，做功快慢由 P = UI 决定。电压越高，电功率越大，同样的砝码被拉得越快、升得越高。演示倍速只改变播放速度，不改变物理计算结果；手动切换电压时，本档实验会从 0 s 和最低位置重新开始。
